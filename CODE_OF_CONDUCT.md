# Code of conduct

Termi's community should be practical, respectful, and safe for people with
different backgrounds and levels of experience.

## Expected behavior

- Discuss code and product decisions without attacking people.
- Give actionable feedback and assume good faith while evidence is gathered.
- Respect privacy; never post another person's terminal output, credentials,
  private paths, or security report without permission.
- Make space for questions and clearly distinguish requirements from personal
  preference.
- Stop behavior when a maintainer asks because it is disruptive or unsafe.

Harassment, threats, discriminatory language, sexualized attention, deliberate
misgendering, doxxing, sustained disruption, and retaliation are not accepted
in project spaces.

## Scope and enforcement

This policy applies to issues, pull requests, discussions, review comments,
project chat, and public interactions made while representing Termi.

Report conduct concerns privately to a repository maintainer. If no private
maintainer channel is available, use GitHub's Report Abuse mechanism; do not
publish sensitive details in an issue. Maintainers may edit or remove content,
warn participants, temporarily restrict participation, or permanently ban an
account based on severity and pattern. Reports will be handled with as much
confidentiality as the platform permits.
